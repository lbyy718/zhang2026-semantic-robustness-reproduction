# “语义通信具有未预期鲁棒性”论证审计

## 审计目标

本文档不预设论文结论必错，而是把论文的经验观察、条件性数学结论和机制归因拆开，避免用一个层面的证据替代另一个层面的证明。

建议将待检验命题写成：

> 论文观察到的高攻击功率，究竟来自语义通信本身，还是来自连续重建任务、随机噪声训练、通信瓶颈、功率归一化、clean-to-threshold 距离或攻击优化不足？

这个命题比“全方位证伪论文”更精确，也允许实验得到支持、部分支持或反对机制解释的结果。

## 论文真正给出的三层结论

### 1. 数学条件命题

论文假设 decoder `g` 是 `G`-Lipschitz：

```math
\|g(y_1)-g(y_2)\|\le G\|y_1-y_2\|.
```

由此建立达到目标失真所需攻击功率的下界。这个方向可以概括为：

```text
G 足够小 + 其他公式条件成立
→ 攻击功率下界较高
```

这是条件命题，不是对训练过程的因果证明。

### 2. 经验观察

论文在特定 CIFAR-10 图像重建配置下报告 DeepJSCC 需要较高的经验攻击功率。经验结果支持“这个已测试配置看起来较难被相应攻击打到指定阈值”。

它不能自动外推到：

- 所有语义任务；
- 所有网络；
- 所有信道和攻击位置；
- 所有攻击算法；
- 所有目标阈值；
- 普通分类鲁棒性；
- 全局认证鲁棒性。

### 3. 机制归因

论文把现象解释为 noisy-channel training 诱导 decoder smoothness。这是合理假说，但需要额外因果对照：

```text
noisy-channel training
→ G 或局部敏感性下降
→ 最小攻击功率上升
```

原实验没有把任务、噪声、结构和 clean margin 完全拆开，因此这条机制链目前证据不足。

## 关键逻辑缺口

### 缺口 1：小 clean distortion 不能推出小 G

若论文得到类似：

```math
D_0\le N\sigma_w^2G^2,
```

则由观测到 `D0` 小，不能反推出 `G` 小。这个不等式把 `G` 放在一个对失真的上界中；上界较松时，即使 `G` 很大，实际 `D0` 仍然可以很小。

因此下列推理无效：

```text
clean reconstruction error 小
→ G 必然小
→ 网络必然鲁棒
```

要支持 `G` 小，需要独立估计/约束局部或全局敏感性，而不是仅根据重建误差倒推。

### 缺口 2：Lipschitz 不等于鲁棒

由有限线性层、卷积层和常见激活组成的普通神经网络通常也可以视为 Lipschitz。关键不是“是否 Lipschitz”，而是：

- 常数是否足够小；
- 使用的是全局常数还是数据附近局部常数；
- 目标任务是否具有足够 margin；
- 理论下界是否非平凡；
- 估计值是否为可认证上界。

分类任务还需要决策 margin。输出变化小不保证标签不翻转，若样本本来就在决策边界附近，小扰动仍可改变类别。

### 缺口 3：局部 Jacobian 不是全局 G

本项目 `theory.estimate_local_lipschitz()` 使用幂迭代估计某个接收点的 decoder Jacobian 谱范数。它适合作为机制诊断，但：

- 只反映一个局部线性化；
- 会随样本、SNR 和激活区域变化；
- 不是整个输入空间的上界；
- 不能直接代入全局 Lipschitz 证明并称为认证结果。

后续实验应把它称为 `local Jacobian spectral norm estimate`，而不是直接称为 `G`。

### 缺口 4：Eq. (12) 的非负条件需要复核

本地 `theory.py` 当前按论文原式计算：

```math
\left(\frac{\sqrt{D^*}}{G}-\sqrt{N\sigma_w^2}\right)^2.
```

如果前一步只得到：

```math
\sqrt{\rho}\ge
\frac{\sqrt{D^*}}{G}-\sqrt{N\sigma_w^2},
```

那么只有右侧非负时才能直接平方。若右侧为负，不等式只提供平凡下界 `rho >= 0`。更谨慎的形式通常应检查：

```math
\left[\max\left(0,
\frac{\sqrt{D^*}}{G}-\sqrt{N\sigma_w^2}
\right)\right]^2.
```

正式批评前应逐行核对论文定理的假设和附录证明；当前把它记录为“待验证的数学边界”，而不是已经确认的错误。

### 缺口 5：经验最小攻击功率未必是真正最小值

PGA 的首次越阈、固定步长和有限迭代只能给出一个经验可行攻击。若没有：

- 多重随机重启；
- 步长敏感性；
- 二分精修；
- 多种强攻击交叉检查；
- 未成功样本的规范处理；

则经验 `rho*` 可能高估真正的最小攻击功率。高估程度若在 DeepJSCC 上更大，会制造“更鲁棒”的假象。

### 缺口 6：固定失真阈值混入 clean margin

若模型 A 的 clean PSNR 是 30 dB，模型 B 是 22 dB，而攻击目标均为 15 dB，A 需要跨越更大的 clean-to-failure 距离。更高攻击功率可能来自初始质量更好，而不完全来自局部平滑。

因此必须同时报告：

- clean performance；
- clean-to-threshold 距离；
- 绝对 `rho*`；
- 对 clean margin 归一化后的鲁棒性；
- 匹配 clean performance 的比较。

## “普通神经网络与本文没有区别”应如何表述

本文可以放进一般神经网络鲁棒性框架，但并非只多了连续重建：

| 特征 | 本文 DeepJSCC | 常见图像分类攻击 |
| --- | --- | --- |
| 攻击位置 | 接收端 latent | 原始输入或特征 |
| 网络结构 | encoder—channel—decoder | classifier |
| 约束 | 发射功率、带宽比、信道使用数 | 输入范数/像素范围 |
| 训练随机性 | 显式信道噪声 | 通常无信道层 |
| 失败事件 | 连续失真超过阈值 | 标签翻转或 margin 过零 |
| 主指标 | 达到目标失真的最小功率 | 固定预算准确率或最小范数 |

更准确的研究判断是：

> 这是一个带随机信道、功率约束和低维瓶颈的神经编码器—任务解码器鲁棒性问题；现有证据不足以证明观察到的效应由“语义通信”这一标签独有地造成。

## 可证伪的子命题

后续实验不应只设一个模糊的“论文正确/错误”判断，而应分别检验：

1. 噪声训练是否降低局部 Jacobian 谱范数。
2. 噪声训练是否提高经验最小攻击功率。
3. 上述效应是否同时存在于重建和分类任务。
4. 重建任务在无噪训练下是否仍显示更高攻击功率。
5. 通信瓶颈和功率归一化是否独立贡献鲁棒性。
6. 匹配 clean performance 后，差异是否仍存在。
7. 更强攻击是否显著压低论文式 `rho*`。
8. `rho*` 的结论是否对目标阈值高度敏感。

## 结果措辞边界

不同结果允许的结论不同：

- 若噪声在分类和重建中都提高鲁棒性：支持一般噪声正则化机制，削弱“语义通信独有”解释，但不反驳“带噪训练可能提高鲁棒性”。
- 若只有重建任务表现鲁棒：支持任务/指标效应，挑战普适推广。
- 若加入强攻击后差异消失：挑战原攻击评估充分性。
- 若通信结构因素独立显著：支持通信瓶颈/功率约束机制，但仍需区分“语义”与“通信结构”。
- 若所有严格控制后效应仍稳定存在：原论文现象得到加强，而不是被证伪。

因此首选表述是“机制拆解与边界检验”，在证据充分后再决定是否使用“证伪”。
