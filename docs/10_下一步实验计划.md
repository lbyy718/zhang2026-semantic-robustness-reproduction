## 1. 当前研究判断

目前已经得到三个可信观察：

1. 使用最佳验证 checkpoint 后，R1/C1 的经验攻击抗性仍高于 R0/C0，因此结果不是简单地拿第 1000 轮严重过拟合模型造成的。
2. AWGN 训练同时伴随 clean margin 增大和局部 Jacobian 谱范数下降；二者都与 PGA 所需扰动增大相容。
3. 分类和重建任务都有同方向现象，所以连续重建不是该现象的必要条件。

但是，当前实验仍没有区分以下解释：

- AWGN 是普通的正则化手段；
- AWGN 主要修复训练信道与测试信道不一致；
- AWGN 真的引入了通信系统特有的鲁棒机制；
- 当前结果被弱分类模型和不同 clean 性能放大。

因此，下一阶段的目标不是继续增加现有 1000 epoch 重复，而是建立更公平、更强的对照。

## 2. 核心研究问题

> 在模型结构、clean 性能和评价协议得到控制后，AWGN 训练带来的 margin、局部 Jacobian 和 PGA 改善，是否仍然存在？这种改善是否也会出现在普通无通信神经网络或常规正则化模型中？

对应假设：

- H1：AWGN 训练的主要收益来自一般正则化和训练—测试信道匹配，而非语义通信独有机制。
- H2：匹配 clean 性能后，AWGN 组可能仍保留部分局部 Jacobian 与 PGA 改善，但幅度会明显小于当前总效果。
- H3：普通无通信分类网络在噪声训练后也会出现相似的相对变化，说明该现象具有一般神经网络性质。

## 3. 第一阶段：先修复分类基线

### 3.1 为什么必须先做

当前分类模型只有约 50,741 个参数：

- 编码器约 9,444 个参数；
- 分类头为 `768 -> 53 -> 10`；
- 没有 RandomCrop、RandomHorizontalFlip、BatchNorm 或学习率调度；
- 10 dB 测试准确率仅约 58%–61%。

它适合作为“与重建 decoder 参数量匹配的小模型”，但不能作为唯一分类基线。后续应同时保留：

- `C-small`：现有约 5 万参数模型，用于参数量匹配；
- `C-strong`：新的强分类通信模型，用于验证结论是否依赖弱模型。

### 3.2 建议的强分类通信模型

建议结构：

```text
CIFAR-10 图像
  -> ResNet 风格卷积编码器
  -> 固定 768 维 latent
  -> 单位功率归一化
  -> AWGN 或无噪声信道
  -> 残差分类头 / 全局平均池化
  -> 10 类 logits
```

必须固定：

- C-strong0 与 C-strong1 使用完全相同的网络结构和参数量；
- latent 维度仍为 768；
- 只改变训练时是否加入 AWGN；
- 两组使用相同训练/验证划分、数据顺序和训练种子；
- 测试时使用相同样本与信道噪声。

训练建议：

- RandomCrop(32, padding=4)；
- RandomHorizontalFlip；
- CIFAR-10 标准化；
- SGD + momentum + cosine，或 AdamW + cosine；
- 训练 100–200 epoch，而不是默认 1000 epoch；
- 验证 CE 作为预先固定的 checkpoint 选择指标；
- 同时记录最高验证 accuracy，但不在实验完成后切换选择规则；
- 训练日志同时保存 train/validation CE、accuracy、margin 和学习率。

### 3.3 第一阶段成功标准

- 单种子 smoke test 完整运行；
- 10 dB 测试准确率至少达到 75%，理想目标为 80% 以上；
- 如果低于 70%，先排查架构、归一化、数据增强和优化器，不进入正式鲁棒性比较；
- C-strong0/C-strong1 的最佳 checkpoint 不应依赖第 1000 轮；
- 先跑种子 2026，协议确认后再扩展到 2027/2028。

注意：C-strong 不再与 R 组做绝对参数量公平比较。它的主要问题是同一强架构内部 `C-strong1 - C-strong0` 的相对效应是否仍存在。

## 4. 第二阶段：拆分过拟合、正则化和信道匹配

### 4.1 训练噪声 × 测试噪声交叉

对同一模型做以下 2×2 评价：

| 训练条件 | 无噪声测试 | 10 dB AWGN 测试 |
|---|---|---|
| 无噪声训练 | A | B |
| 10 dB AWGN 训练 | C | D |

主要解释：

- A 好、B 明显差：存在训练—测试信道失配；
- C 和 D 都优于 A 和 B：更支持一般正则化/平滑；
- 主要只有 D 优于 B：更支持信道分布匹配；
- 在 clean 性能匹配后差异消失：原始鲁棒收益主要由泛化性能差异造成；
- 在 clean 性能匹配后仍保留 Jacobian/PGA 差异：存在超出 clean margin 的局部敏感性变化。

不要只评估 10 dB。至少同时报告无噪声、10 dB；完整曲线可继续使用 0–20 dB。

### 4.2 常规正则化对照

在不加入 latent AWGN 的情况下，增加一个 `REG` 组：

```text
无 latent 信道噪声
+ 相同基础数据增强
+ 更合理的 weight decay
+ early stopping
+ 可选 label smoothing 或 dropout
```

为了避免一次改变太多因素，建议分两步：

1. `REG-basic`：只调 weight decay + early stopping；
2. `REG-strong`：再加入 label smoothing 或 dropout，二选一，不同时全部加入。

比较对象：

- AWGN vs 无噪声普通训练；
- REG vs 无噪声普通训练；
- AWGN vs clean 性能相近的 REG。

如果 REG 在相近 clean accuracy/margin 下得到与 AWGN 相近的 Jacobian 和 PGA 改善，则强烈支持“一般正则化”解释。

### 4.3 如何处理 clean 性能不公平

主分析仍使用各组按统一规则选出的最佳验证 checkpoint，表示训练流程的总效果。

另外增加一个机制型次分析：

- 保存训练过程中的候选 checkpoint；
- 在验证集上寻找 clean accuracy 接近的模型对，分类容差建议为 1 个百分点；
- 同时检查 margin 分布，不能只匹配平均准确率；
- 在固定好的匹配规则下比较 Jacobian、局部线性距离和 PGA；
- 匹配规则必须在看测试攻击结果之前确定。

这比训练完成后匹配不同测试图片更接近公平模型比较，但仍应与总系统效果分开报告。

## 5. 第三阶段：增加真正的无通信对照

当前 C0/C1 仍包含 768 维通信瓶颈，不能证明“通信结构完全不必要”。因此需要普通 CIFAR-10 ResNet 对照：

| 条件 | 模型 | 训练扰动 |
|---|---|---|
| N0 | 普通 ResNet-18 | 无输入噪声 |
| N1 | 普通 ResNet-18 | 输入高斯噪声 |
| NREG | 普通 ResNet-18 | 常规正则化增强 |

评价：

- clean accuracy 和 margin；
- 输入 Jacobian 局部谱范数；
- 输入空间 PGA 所需 L2；
- 相同架构内 N1/N0、NREG/N0 的相对变化。

注意：像素输入攻击和 latent 攻击的维度、尺度和物理含义不同。因此不要直接比较 N 组与 R/C 组的绝对 PGA 功率，只比较各自架构内部的相对变化方向和倍率。

如果 N1/N0 同样出现：

```text
clean margin 增大
+ Jacobian 谱范数下降
+ PGA 所需扰动增大
```

那么可以更有力地说明：论文现象至少不需要语义通信结构，是一般神经网络噪声训练可以产生的现象。

## 6. 第四阶段：统一机制评价

只有在强分类基线和无通信对照达到合理 clean 性能后，才运行完整机制诊断。

每组至少记录：

- clean accuracy；
- clean margin；
- failure-score gradient L2；
- 局部 Jacobian 谱范数；
- linearized distance；
- PGA attack L2；
- PGA 成功率和步数；
- train/validation gap；
- best epoch。

主报告分成两层：

1. **Total effect**：全样本系统效果，保留 clean 性能和 margin 带来的收益；
2. **Mechanism-oriented effect**：共同 clean-correct、模型 clean 性能匹配和样本 margin 匹配，仅作条件敏感性分析。

不得把局部 Jacobian 谱范数写成全局 Lipschitz 常数 `G`，也不得把 `rho_lin = margin / gradient` 的代数恒等式写成因果分解。

## 7. 种子、攻击与计算预算

### 7.1 推荐顺序

1. 单种子 smoke：确认强模型训练和指标管线；
2. 单种子正式 pilot：确定准确率、训练时长和最佳 epoch 范围；
3. 三个训练种子：2026、2027、2028；
4. 如果三种子方向不一致或标准差很大，再扩展至五个种子；
5. 最后才运行逐样本 Jacobian/PGA 诊断。

### 7.2 攻击策略

当前研究重点不是寻找最强攻击，因此：

- PGA 继续作为主攻击；
- 固定步长、最大步数、样本和随机数；
- 明确它是经验攻击而非认证鲁棒性；
- 可用少量样本做一次 C&W 或更细步长审计，确认 PGA 排序没有明显反转；
- 不必现在扩大到大量攻击算法。

### 7.3 预计作业数量

最小正式版本：

- C-strong0/C-strong1：2 条件 × 3 seeds = 6 次训练；
- REG-basic：1 条件 × 3 seeds = 3 次训练；
- N0/N1/NREG：3 条件 × 3 seeds = 9 次训练；
- 总计 18 次训练，先用 pilot 估算单次时间再启动批处理。

机制诊断可以继续使用 3 个共享噪声重复，但统计推断单位必须保持为训练种子，而不是把 sample × repeat 当成独立样本量。

## 8. 判定矩阵

| 最终结果 | 合理结论 |
|---|---|
| 强 C、普通 ResNet 和 REG 都出现相似改善 | 强烈支持一般噪声训练/正则化解释 |
| 只有通信 C/R 的 latent AWGN 有效 | 支持通信瓶颈或信道匹配的重要性，但仍不是认证鲁棒性 |
| AWGN 优势在 clean 性能匹配后消失 | 原始现象主要由泛化、margin 或过拟合差异造成 |
| 匹配后 Jacobian/PGA 仍稳定改善 | 存在独立于平均 clean 性能的局部平滑信号 |
| 三个种子方向不一致 | 当前效应不稳定，需要更多种子或重新检查训练协议 |
| 强分类基线中效应消失 | 旧结论可能依赖弱模型容量与优化缺陷 |

## 9. 停止条件

满足以下条件后再形成论文级结论：

- 强分类通信模型达到预设 clean 性能门槛；
- 至少三个独立训练种子完成；
- 训练噪声 × 测试噪声交叉完成；
- 至少一个常规正则化对照完成；
- 至少一个真正无通信网络对照完成；
- total effect 与 clean-performance/margin-controlled effect 分开报告；
- Jacobian 与 PGA 的主要方向在种子层面可复核；
- 所有结论明确限定为经验鲁棒性和局部敏感性。

## 10. 立即执行顺序

下一步只做下面四件事，不立即启动全部 18 次训练：

1. 实现 `C-strong` 模型和对应配置；
2. 为训练数据加入可配置的 CIFAR-10 数据增强和标准化；
3. 加入学习率调度、early stopping、最高 accuracy/最低 CE 双记录，但预先固定正式 checkpoint 规则；
4. 只运行 seed 2026 的 C-strong0/C-strong1 pilot。

Pilot 通过准确率、日志完整性和训练稳定性验收后，再生成三种子批处理脚本。这样可以避免再次用一整晚计算验证一个本应先在单种子上发现的训练配置问题。

## 11. 下一阶段可形成的最强结论

如果强分类、普通 ResNet 和常规正则化对照均得到一致结果，届时可以较有力地写成：

> 所谓语义通信的“意外鲁棒性”可以在不依赖连续重建、甚至不依赖通信结构的普通神经网络中，通过噪声训练或常规正则化复现。其经验表现主要与泛化改善、clean margin 增大及局部输入—输出敏感性下降有关，因此现有证据不足以把该现象归因于语义通信特有机制。

在这些对照完成前，仍应使用较保守的表述：

> 当前结果支持一般噪声训练解释，并削弱语义通信特异性解释，但尚未彻底排除通信瓶颈或信道匹配的作用。
