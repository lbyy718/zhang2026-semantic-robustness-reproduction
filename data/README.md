# CIFAR-10 data

The dataset is not committed to Git. The image configurations use `torchvision.datasets.CIFAR10` with `download=true`, so the first training or evaluation run prepares:

```text
data/
└─ cifar10/
```

The expected original archive checksum is:

```text
MD5 c58f30108f718f92721af3b95e74349a
```

The dataset remains local because its original license and redistribution terms apply.
